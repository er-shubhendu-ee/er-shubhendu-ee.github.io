Project

Industrial Communication Platform

Development of industrial communication firmware and monitoring systems based on Modbus RTU over RS485 networks. The platform enabled reliable communication between embedded controllers, Human Machine Interfaces (HMIs), and industrial equipment for monitoring, configuration, control, and data acquisition.

The project focused on robust communication design, fault tolerance, and long-term operation in electrically noisy industrial environments.

Responsibilities

Key Contributions

  • Development of Modbus RTU Master firmware.
  • Development of Modbus RTU Slave firmware.
  • RS485 communication stack implementation.
  • Register mapping and protocol integration.
  • Delta HMI integration and configuration.
  • Industrial equipment communication.
  • System monitoring and parameter configuration.
  • Timestamped operational data logging.
  • Communication fault handling and recovery.

System Architecture

Communication Design

The system consisted of embedded controllers connected through RS485 networks using the Modbus RTU protocol. Devices operated as Modbus Masters and Slaves depending on system requirements, allowing centralized monitoring and distributed control.

Delta HMI panels were integrated to provide operator interfaces for process visualization, parameter adjustment, alarm handling, and historical data access.

Firmware Development

Embedded Implementation

  • UART-based Modbus RTU protocol implementation.
  • RS485 transceiver control and bus management.
  • CRC generation and validation.
  • Master polling mechanisms.
  • Slave request processing.
  • Communication timeout management.
  • Error detection and recovery strategies.
  • Real-time parameter monitoring and control.

HMI Integration

Operator Interface

Delta HMI systems were configured to communicate with embedded controllers using Modbus RTU. Custom interface screens were developed for device monitoring, parameter configuration, diagnostics, alarm reporting, and timestamped event logging.

The resulting interface simplified operation while providing real-time visibility into system status and process variables.

Technical Challenges

Engineering Focus Areas

  • Operation in electrically noisy industrial environments.
  • Communication timeout and fault recovery.
  • Multi-device network management.
  • Data integrity verification using CRC.
  • Robust handling of communication interruptions.
  • Field deployment and troubleshooting.

Results

The platform delivered reliable industrial communication between controllers, HMIs, and field equipment, enabling real-time monitoring, configuration, and operational data collection. The resulting firmware architecture remains suitable for industrial automation, process control, and machine monitoring applications.
